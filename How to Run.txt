ONE-CLICK INSTALLER (recommended for end users)
-----------------------------------------------
1. Install Inno Setup 6 once on the BUILD PC:
     https://jrsoftware.org/isdl.php

2. Double-click:
     MakeInstaller.cmd

   Or run:
     powershell -ExecutionPolicy Bypass -File .\BuildInstaller.ps1

3. Result:
     dist\PrintArchive-Setup.exe

4. On the target PC: double-click PrintArchive-Setup.exe, accept UAC.
   It installs the service, agent, and opens the password UI.


DEV INSTALL (no Setup.exe)
--------------------------
  powershell -ExecutionPolicy Bypass -File .\Build.ps1
  powershell -ExecutionPolicy Bypass -File .\installer\Setup.ps1

Hotkey after install: Ctrl+Alt+F12
